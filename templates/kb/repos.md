# Repos

The repos YBase manages. This list is private: it lives here, never in YBase itself. Each row needs a name, one line on what the repo is, an optional git remote, and an optional hint for agents.

Local paths are not recorded here. They come from `YBASE_REPOS_ROOT` or `YBASE_REPO_PATH_<NAME>` in YBase's `.env`; `ybase repos` shows the result. Past about 20 repos, move rows into `repos/<area>.md` files that use the same table.
